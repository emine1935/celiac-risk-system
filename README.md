# Çölyak Hastalığı Risk Analiz Sistemi

## Proje Açıklaması

Bu proje Flask tabanlı bir web uygulamasıdır.

Kullanıcıların yaş ve belirtilerini kullanarak çölyak hastalığı risk seviyesini hesaplar.

Yapılan analizler SQLite veritabanında saklanır ve yönetici panelinden görüntülenebilir.

## Kullanılan Teknolojiler

* Python
* Flask
* SQLite
* HTML
* CSS
* Git
* GitHub

## Özellikler

* Risk analizi
* Sonuç ekranı
* Veritabanı kayıt sistemi
* Yönetici paneli
* Analiz geçmişi görüntüleme

## Veritabanı Yapısı

Tablo: analizler

Alanlar:

* id
* yas
* karin_agrisi
* ishal
* risk
